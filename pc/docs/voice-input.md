# 设备按键语音输入

## macOS

1. 保持设备 USB 连接，Pet Manager 运行，配置好语音识别并启用按键语音。
2. 在目标应用点击输入位置，按住语音键说话（默认 1 键），松开。
3. 识别完成后，完整文字一次粘贴到当时有焦点的输入框。不启动或切换应用，不自动发送；需要发送时在目标应用手动操作。

可以多次录音继续输入。行为与普通粘贴一致：在光标处插入，有选区时替换选区。录音期间可以切换目标，但识别完成到粘贴之间请保持焦点稳定；如果此时焦点变化，停止本次写入。

该功能通过 macOS 辅助功能读取输入焦点，使用定向粘贴完成输入，无需安装系统输入法。第一次使用在「语音输入」提示中主动请求 Pet Manager 的辅助功能权限。不需要输入监控权限，不自动修改系统授权。

支持通过辅助功能公开文本输入焦点的普通文本框、浏览器输入框及终端。密码框、明确禁用或只读的控件、未公开可输入焦点的应用不支持。没有焦点或权限不足时，识别文字保留在客户端，不转发给所选 Agent。能读取控件文本值时，客户端会等待目标应用确认文字变化；不能读取时只报告粘贴事件已投递，请核对文字。不自动重试，以免重复输入。

粘贴前备份剪贴板，操作后恢复；如果用户期间复制了新内容，则保留用户的新剪贴板。前台应用不同不影响语音识别 API 的配置要求；所选 Agent 只用于设备状态展示。

「诊断与测试」可输入本地测试文字，点击「5 秒后粘贴到当前光标」后切到目标输入框。测试不录音、不调用 ASR/TTS、不发送回车；请先结束设备录音。

## 其他平台

继续使用现有 Agent 会话输入路径。本文的系统焦点输入能力目前只在 macOS 实现；Windows 不显示该能力已可用。
