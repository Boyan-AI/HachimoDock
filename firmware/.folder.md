# ESP32-P4 固件目录

0.7.73-p4-rc.1：语音修复预发布。v3 使用 FD AEC 以满足实机实时预算，v1 保留 VOIP；分区不变。版本与干净源码构建标识由 `CMakeLists.txt` 和 `platformio.ini` 注入，配套桌面端为 0.1.102-rc.1。

- `platformio.ini`、`dependencies*.lock`：分别锁定 v1 与 v3 的构建环境。
- `main/`：USB 协议、动画渲染、输入、组件运行时、实时数据与音频前端。
- `components/`：板级和显示支持；保留各组件原始许可证。
- `tools/`：内置资源及完整出厂镜像生成工具。
- `tests/`：主机侧协议、音频、资源和组件契约回归。
- `factory-config.json`：出厂组件与资源配置。

构建见 `BUILD.md`，协议见 `protocol.md`。v1 与 v3 必须使用各自对应的镜像，不能互刷；具体芯片版本可咨询客服确认。日常升级使用 PC 端 OTA；完整出厂烧录会覆盖配置与资源。
